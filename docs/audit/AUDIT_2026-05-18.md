### Điểm tích cực đã xác nhận (không cần sửa)
- Commit-reveal domain-separated: `keccak256(chainid, address(this), voter, candidateId, salt)`; Merkle leaf chuẩn OZ `StandardMerkleTree`.
- Chặn double-commit/double-reveal/commitment-mismatch/unknown-candidate; không có bề mặt reentrancy; election immutable sau deploy.
- Backend wallet-bind dùng EIP-191 ecrecover đúng; rule "ví admin phải thuộc account đang đăng nhập" được enforce qua claim `DiaChiVi`; node helper gọi bằng `ArgumentList` (không shell ⇒ không command injection); refresh token SHA-256 hashed.
- Frontend active path (create → QR/OTP → commit/reveal/finalize) đã modern, Sepolia-correct, backend-driven.
- `npm audit` contracts: 0 vuln; OZ v5 pinned; Solidity 0.8.28 + optimizer + viaIR nhất quán Hardhat/Foundry.

## 4. Khoảng trống "one-command bring-up"

1. `blockchain_sm/.env` bắt buộc nhưng vắng trên fresh clone (chỉ có `.env.example`). Stack *start* được nhưng **create-election fail runtime** vì thiếu `SEPOLIA_PRIVATE_KEYS`/`FACTORY_ADDRESS`.
2. Prereq ngoài repo không lấy được từ code: key ví **Sepolia có ETH**, **RPC URL**, **`FACTORY_ADDRESS` đã deploy** (không có script/bước deploy factory trong docs), Gmail SMTP app-password (optional).
3. Không có Anvil local-chain ⇒ không chạy offline được.
4. Không persistence cho deployment records (S15) + không health gating (FE ready trước backend).
5. Doc trỏ path sai (S20).

**Tối thiểu để one-command:** ship `blockchain_sm/.env` template với `FACTORY_ADDRESS` testnet dùng chung + key throwaway có ETH, **hoặc** thêm profile `anvil` deploy factory cục bộ; fix path runbook; thêm backend healthcheck + FE health gate; thêm volume cho deployment artifacts.
